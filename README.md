# JUST-ME

A server-rendered web application built with Express and EJS.

## About The Project

An Express application organized in an MVC structure (`mvc/routes`, `mvc/views`), using EJS as the view engine, with cookie parsing, HTTP error handling and request logging.

### Built With

- Node.js + Express
- EJS

## Getting Started

### Prerequisites

- Node.js

### Installation

```sh
npm install
npm start        # node ./bin/www
```
